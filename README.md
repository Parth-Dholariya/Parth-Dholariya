## Featured Research

### GeoAgri-Shield: Parcel-Scale Crop Loss Framework

- Processed **10 m Sentinel-2 imagery** using a seven-channel spectral-index stack
- Trained a Random Forest model achieving **98.49% accuracy**, **0.93 κ**, and **95.74% F1**
- Evaluated the model on **1.43 million test pixels**
- Developed parcel-level crop-damage, inundation, and relief-allocation analysis
